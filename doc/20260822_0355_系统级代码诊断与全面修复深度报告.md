## 一、本次深度排查发现并彻底修复的 6 项核心 Bug

依据 `diagnosing-bugs` 方法论（构建严苛红灯测试环路 → 最小化重现 → 根因假设 → 精准打桩修复 → 回归测试），逐模块发现并修复了以下 6 项逻辑与数学缺陷：

### 1. 🔴 SAPIEN 3 真实光学相机外参求逆崩溃与坐标系未对齐（严重）
- **触发文件**：`vlm_active_search.py` L66
- **根本原因**：SAPIEN 3 中 `cam.get_extrinsic_matrix()` 返回形状为 `(3, 4)`，直接执行 `np.linalg.inv()` 必然抛出 `numpy.linalg.LinAlgError: Last 2 dimensions of the array must be square`。同时 SAPIEN 相机本地为 OpenGL 坐标系（-Z 前向），而反投影函数 `backproject_pixel_to_3d` 采用 OpenCV 坐标系（+Z 前向）。
- **修复方案**：将变换矩阵重构为 `T_world_cam = cam.get_model_matrix() @ np.diag([1.0, -1.0, -1.0, 1.0])`，数学证明并实机测试确认反投影与真实三维空间完全重合。

### 2. 🟡 VLM 语义回退模式覆盖不全导致类别识别错误（逻辑缺陷）
- **触发文件**：`vlm_detector.py` L124-136
- **根本原因**：语义回退匹配逻辑仅硬编码了桌子、冰箱、沙发 3 类。如果对“大床”、“书架”、“电视”、“椅子”、“衣柜”触发回退，系统会默认错误识别为“桌子”。
- **修复方案**：补齐 GRScenes 全部 11 大类典型家居实体语义词表与对应 Bounding Box，使回退模式与大模型推理保持 100% 覆盖一致性。

### 3. 🟡 环视候选视角筛选关键词截断（逻辑缺陷）
- **触发文件**：`grscene_vlm_nav.py` L156-163
- **根本原因**：多视角初筛 `expected_tokens` 仅支持 5 种家具，当用户下达“去椅子旁边”、“去冰箱前面”、“去衣柜前面”时，筛选词表为空导致候选集被判空，无法选出最优视角。
- **修复方案**：全量扩展匹配词表并加入自然语言字符容错提取机制。

### 4. 🟡 Gymnasium 训练环境复位时目标点可能落入大型家具内部（动力学缺陷）
- **触发文件**：`r2_grscene_env.py` L202
- **根本原因**：`reset()` 采用固定偏移 `p[0]-0.70, p[1]+0.40`，对于 2.6m 餐桌或 4.1m 大沙发，停靠目标直接落入刚体碰撞体内部，导致机器人碰撞受阻，产生负奖励截断。
- **修复方案**：在 `reset()` 中接入 `compute_standoff_waypoint(..., obj_half_extents=[sx/2, sy/2])`，确保在任何户型中目标点均安全坐落于家具外缘。

### 5. 🟡 全场景 PPO 训练脚本观测维度（线速度/角速度）特征缺失（分布偏移）
- **触发文件**：`train_full_69_scenes_ppo.py` L85-88
- **根本原因**：训练循环中 `obs_vec[50]` 和 `obs_vec[51]` 遗留为 0.0，而测试环境输入了实时线速度与角速度，存在特征分布偏移。
- **修复方案**：在训练循环中实时跟踪上一时刻线速度与角速度命令，规范化填充 `obs_vec[50:52]`。

### 6. 🟡 全场景 PPO 训练激光雷达忽略非目标家具障碍（感知漏洞）
- **触发文件**：`train_full_69_scenes_ppo.py` L71-80
- **根本原因**：雷达模拟仅射线检测了墙体 `walls_info`，室内其他 20 余件大件家具未作为障碍物遮挡，使策略在训练时无法感知家具间隙。
- **修复方案**：将场景内所有非目标家具同等合并入障碍物列表执行雷达遮挡射线解算。
