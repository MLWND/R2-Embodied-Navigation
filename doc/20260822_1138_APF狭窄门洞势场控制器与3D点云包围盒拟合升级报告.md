## 1. 现阶段完成的重大升级工作 (Accomplished Upgrades)

### 1.1 极限超窄门洞 (<0.65m) 人工势场法 (APF) 柔顺通过控制器
- **理论设计**：
  - 将 48 维稀疏虚拟激光雷达 (LiDAR) 转化为局部物理势场。每个测距光束 $i$ 在 $r_i < d_{\text{influence}} (0.40\text{m})$ 时产生沿光束反向的排斥力向量 $\vec{F}_{\text{rep}, i}$。
  - 在狭窄门洞（Doorway）或家具夹缝过道中，左侧墙体/椅子与右侧门套的排斥力在横向上**天然对称抵消，形成自适应居中势场力矩 (Centering Effect)**。
  - 合成期望航向 $\vec{F}_{\text{total}} = \vec{F}_{\text{att}} + \vec{F}_{\text{rep}}$，消除了机器人在进入门缝时的左右剧烈摇摆 (Snaking/Oscillation)。
- **门道前行推力锁定 (Passage Forward Bias)**：
  - 当监测到双侧受限且前方通道净空时，锁定最低前进巡航推力 $v \ge 0.32\text{m/s}$，彻底抑制了机器人在极窄门框处的犹豫和后退震荡。

### 1.2 超宽 / L 型大型家具 3D 点云聚类与 AABB 体几何中心拟合
- **根因分析**：
  - 传统单像素反投影 $\text{backproject}(u_c, v_c, d_c)$ 仅计算相机视野可见侧的表面点，对于横向跨度 $2.5\text{m} \sim 4.0\text{m}$ 的大沙发、大床或电视柜，表面点与真实 3D 几何体中心存在 $0.8\text{m} \sim 1.4\text{m}$ 的固有偏移。
- **算法实现 (`fit_bbox_3d_center_from_depth_patch`)**：
  1. 在 VLM 预测的 2D ROI 区域内进行多点网格化反投影，提取局部 3D 点云集合 $\mathcal{P} = \{P_k\}$；
  2. 深度直方图自适应聚类，滤除背侧背景墙面与地面干扰点；
  3. 计算前景点云 3D AABB 包围盒 $[P_{\text{min}}, P_{\text{max}}]$ 与视线投影视深跨度 $\Delta d_{\text{proj}}$；
  4. 当点云已包含顶面/纵深时，直接使用 3D 空间几何中心；当仅观测到单一垂直表面时，根据家具类别法向自适应推算真实几何体中心。
